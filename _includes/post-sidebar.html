Related posts are scored in Liquid rather than using site.related_posts, which without the LSI plugin is just "the 10 most recent posts" and is therefore wrong on a blog where the newest post is rarely the most relevant one. LSI needs classifier-reborn, which GitHub Pages does not allow. The score is (shared tags * 2) + (same category * 3). Entries are built as sortable strings because Liquid cannot sort an array of objects by a value it just computed. {%- endcomment -%} {%- assign scored = "" | split: "" -%} {%- for other in site.posts -%} {%- if other.url != page.url -%} {%- assign score = 0 -%} {%- for tag in other.tags -%} {%- if page.tags contains tag -%} {%- assign score = score | plus: 2 -%} {%- endif -%} {%- endfor -%} {%- for category in other.categories -%} {%- if page.categories contains category -%} {%- assign score = score | plus: 3 -%} {%- endif -%} {%- endfor -%} {%- if score > 0 -%} {%- assign padded = score | prepend: "0" | slice: -2, 2 -%} {%- assign entry = padded | append: "|||" | append: other.url | append: "|||" | append: other.title -%} {%- comment -%} Liquid has no push filter; splitting on an absent token yields a one-item array to concat. {%- endcomment -%} {%- assign entry_item = entry | split: "@@no-split@@" -%} {%- assign scored = scored | concat: entry_item -%} {%- endif -%} {%- endif -%} {%- endfor -%} {%- assign ranked = scored | sort | reverse -%}
